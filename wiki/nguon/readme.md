# README – Ứng dụng xử lý PDF ảnh

**Tóm tắt.** Giới thiệu dự án, cách cài và chạy [[nguyen-mau-windows]] (Python + OpenCV + Tesseract), bảng trạng thái 6 tính năng, cách dùng giao diện, dòng lệnh và kiểm thử. Mọi xử lý chạy trên máy, không gửi dữ liệu đi đâu.

## Ý chính
- Nguyên mẫu Windows làm trước để thử thuật toán trên ảnh thật, rồi mới chuyển sang C++/Flutter ([[flutter-loi-cpp]]).
- Cài: Python ≥ 3.10, Tesseract có gói `vie`; chạy `cai-dat.bat` rồi `chay-ung-dung.bat`; tùy chọn `them-vao-send-to.ps1` thêm mục *Gửi tới > Xử lý PDF ảnh*.
- Trạng thái tính năng:
  - 1 Chụp, xuất PDF: webcam/camera tài liệu, [[tu-dong-chup]], mở JPG/PNG/TIFF/HEIC/WebP, xuất PDF gộp.
  - 2 Làm sáng nền, giữ màu: chế độ giữ màu, xám, đen trắng; chỉnh độ trắng nền, độ đậm chữ ([[lam-sach-giu-mau]]).
  - 3 Xoay, nắn phẳng, gộp: phối cảnh, xoay 90°/180°, sửa nghiêng, tách trang đôi, kéo 4 góc khung cắt; **chưa có** nắn trang sách cong ([[nan-phang-va-xoay]]).
  - 4 Tự xử lý tệp nhận được: kéo thả, *Gửi tới*, xử lý theo lô, thư mục theo dõi.
  - 5 Nhận dạng, sửa chữ: OCR Việt–Anh, PDF có lớp chữ, xuất .txt; **chưa có** sửa chữ khớp font ([[nhan-dang-va-sua-chu]]) (bản 2026-10-29). Bản 2026-10-30: đã có **sửa chữ trên trang** trong cửa sổ Sửa PDF ([[cua-so-sua-pdf]]). Bản 2026-10-30 (lần 2): dòng 5 đổi thành **sửa chữ theo khối (dòng, đoạn), gõ ngay trên trang**; dàn lại chữ mới khớp phông, cỡ, màu, căn lề, khoảng cách dòng; phần dưới dời theo.
  - 6 Chỉnh định dạng: khổ giấy, lề, chất lượng ảnh khi xuất; **chưa có** trình soạn thảo font, cỡ chữ.
- Dòng lệnh: `tu_dong.py xu-ly …` (theo lô, `--gop`, `--kho`, `--le`, `--ocr`, `--txt`) và `tu_dong.py theo-doi <thư mục>`.
- Kiểm thử: `tao_anh_mau.py`, `kiem_thu_loi.py`, `kiem_thu_tu_chup.py`; từ 2026-10-30 thêm `kiem_thu_sua_pdf.py` ([[kiem-thu]]). Ảnh tổng hợp chưa thay được ảnh chụp thật.
- Không dùng MuPDF (AGPL): đọc PDF bằng PDFium, ghi bằng reportlab và pypdf ([[giay-phep-thu-vien]]).
- Thư viện Python (`ung-dung/requirements.txt`): opencv-python ≥ 4.8, numpy, Pillow, pillow-heif, pypdfium2, pypdf, reportlab, pytesseract, watchdog, tkinterdnd2.
